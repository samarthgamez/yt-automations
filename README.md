# 🎬 YouTube Automation with Claude

Automate your YouTube content workflow using Claude AI. This project helps
creators save time by handling the repetitive parts of video production, so
you can focus on making great content.

## ✨ Features

- **Idea generation**: Get trending, niche-specific video ideas
- **Script writing**: Generate full video scripts in your tone and style
- **SEO optimization**: Create titles, descriptions, and tags that rank
- **Thumbnail text ideas**: Catchy hooks to boost click-through rate
- **Upload automation**: Publish videos via the YouTube Data API
- **Batch processing**: Plan and generate content for multiple videos at once

## 🚀 Getting Started

1. Clone the repo
   git clone https://github.com/your-username/your-repo.git
   cd your-repo

2. Install dependencies
   pip install -r requirements.txt

3. Add your API keys in a `.env` file
   ANTHROPIC_API_KEY=your_key_here
   YOUTUBE_API_KEY=your_key_here

4. Run the project
   python main.py

## 🛠️ Tech Stack

- Claude API (Anthropic)
- YouTube Data API v3
- Python
